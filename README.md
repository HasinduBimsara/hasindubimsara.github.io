# Hasindu Bimsara — Portfolio

A responsive static portfolio inspired by the [Sawad layout](https://sawad.framer.website/), personalized with my projects, education, and technical skills.

## Local preview

Run `python -m http.server 4173` from this folder, then open http://localhost:4173.

## Site files

- `index.html`: portfolio content and project details.
- `styles.css`: responsive layout, colors, and typography.
- `script.js`: project filters, accessible project dialogs, navigation, and contact actions.
- `Images/`: portrait, project previews, and certificates.

The contact form opens a prefilled email draft in the visitor's email app. It does not send messages through a server. The résumé links to the existing Google Drive file.

## GitHub Pages

Publish the repository's `main` branch from `/ (root)` in Settings → Pages. Include `index.html`, `styles.css`, `script.js`, and `Images/` when committing changes. No build or package installation is needed.
